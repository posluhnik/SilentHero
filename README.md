Installation:
1. Download zip file and open it in any folder you want.
2. Or you can type into your console: `bash` and then `git clone [https://github.com/posluhnik/SilentHero.git](https://github.com/posluhnik/SilentHero.git)`


How to launch this program:
There are two ways to proceed:

1\. Via the console:

Open the console in that folder.

Type: `dotnet run`.

2\. Via Visual Studio:

Simply open the project in Visual Studio and run it.



Rules and warnings:

1\. Do not resize the console window, or the interface layout will break.

2\. Ideally, the console should be 120 characters wide and 30 lines high.

3\. It is recommended to run the program via Visual Studio, as it automatically sets the console size for a comfortable gaming experience.
